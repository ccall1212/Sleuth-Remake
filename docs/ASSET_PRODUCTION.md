# ASSET_PRODUCTION.md: Mansion Mystery configuration for the `asset-production` skill

Written 2026-11-23. Project rules in `AGENTS.md` and `docs/IMAGE_ASSET_WORKFLOW.md` override the skill.

1. **Engine:** Godot 4. Runtime character art is loaded by `src/mystery/case_actor_art.gd` through each character's `directional-index.json`; pose status for the game is in `assets/characters/poses/runtime-integration.json`.
2. **Art style and canvas:** richly shaded, outlined anime/cartoon rendering (not redesigned as low-res pixel art). Real PNG alpha transparency. Each character's native canvas and standing height are in `assets/characters/poses/<slug>/profile.json` (Chris 948x1659 / 1564 px, Kwinn 985x1597 / 1572, Sarah Jo 987x1593 / 1590). Alpha 240 to 254 on the subject is normal for the generator and not a failure. Seated, kneeling, crouching and lying poses keep standing-relative scale.
3. **Naming and folders:** `<slug>_<posture>_<action>_<direction>_<variant>.png`; drafts in `assets/characters/poses/<slug>/drafts/<pack>/`, masters in `masters/`, approved exports in `exports/<north|east|south|west|murderer-reveal|lying>/`. Prompt pages in `<slug>/prompts/<pack>/`; attachment copies in `test-results/pose-batches/<slug>/batch-NN/` (git-ignored). Records: `directional-index.json` (per pose approval label and hash), `production-manifest.json`, `queue.json` (Chris only), `decisions.json` (the user's recorded decisions), `drafts/*/candidates.json` (base-model approvals).
4. **Identities and references:** Char is the composition example for women (Sarah Jo) and the first-pass example for tier work; Chris is the composition example for men (Kwinn); Chris's own references were Char's. A reference must have an index record and a matching hash; the recorded status (approved, user_supplied_added_to_project, reference_only) is kept and shown in the prompt. Char's three standing_clasp_hands images are reference_only and may be used only as linked reference examples (`char/decisions.json`). Men use the crouching cry for the crying slot, women use the standing cry (`production-plan.json` `body_template_choices`).
5. **Approval rules:** only the user's own words approve (record the quote, date, paths, SHA-256, scope; `python tools/check_image_approval.py <record>`). Base-model approval is not pose approval. Standing draft allowance: drafts may be generated without waiting, up to **24 unreviewed drafts per character and 48 in total** (awaiting-review drafts count). Never commit, push or merge without the user's say.
6. **Runtime integration:** separate from approval and from fit; never claimed from approval. Lying poses are art-only until beds can be walked on.
7. **Commands** (run from the repo root; Python is `.venv\Scripts\python.exe`):
   - **next:** `.venv\Scripts\python.exe assets/characters/poses/tools/pose_runner.py --character <slug> next` (add `--group`, `--directions`, `--max-batch`).
   - **build:** `.venv\Scripts\python.exe tools/build_pose_prompt_pack.py <slug> [--group <id>] [--directions east west] [--max-batch N] [--dry-run]`.
   - **check:** `.venv\Scripts\python.exe tools/check_pose_drafts.py <slug> --html [--pack pack-01]`.
   - **reconcile:** `.venv\Scripts\python.exe assets/characters/poses/tools/pose_runner.py --character <slug> reconcile`; `manifest-sync` (report only unless `--write`).
8. **Planning data:** `assets/characters/pose-catalog.json` (poses, optional fields `eligible_characters`, `exclude_characters`, `eligible_body`, `reuse_from`, `excluded`), `assets/characters/poses/production-plan.json` (groups: idle, reaching, kneeling, conversation, suspicion-defense, emotion, reveal, personality-gestures, reading-and-props, seated, lying; batch max 8; reference policy), `assets/characters/poses/<slug>/profile.json`.

**Full paths / GitHub handoff:** every handoff prompt gives each file as a complete location, never "the batch folder", because a prompt may be pasted into a new chat with no other context. `tools/build_pose_prompt_pack.py` writes `prompts/<pack>/batch-NN.md` for an assistant that reads GitHub: each reference is a full `raw.githubusercontent.com` URL built from the git remote and current branch (no personal paths), so nothing is attached by hand. The batch `.md`, the character's base model and the example character's approved exports must be committed and pushed to that branch first, which only the user authorizes. The local HTML pages use project-relative paths.

Current scope (user, 2026-11-23): the 81 core poses plus kneeling inspect east, south and west; all other tier-4 poses and kneeling inspect north are excluded. Kwinn and Sarah Jo have only their approved standing idle (south) imported; everything else is produced with this workflow.
