# kwinn: pose prompt pack 01

81 core poses (tiers 1-3; tier 4 is held because no matching Char art exists). Open `index.html`, work in tier order.

For each card: (1) attach the two reference images, (2) paste the prompt, (3) save the result with the **exact file name shown** into
`assets/characters/poses/kwinn/drafts/pack-01/` (create the folder), (4) tell Claude the pose is ready. A draft is not approved until you say so
in your own words; Claude then imports it, records the approval and checks size and transparency. Do about eight at a time so reviews stay manageable.
